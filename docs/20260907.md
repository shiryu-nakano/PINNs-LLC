外部での再構成
python
def forward(params, prefix, X, X_mean, X_std, num_layers):
    H = (np.concatenate(X, axis=1) - X_mean) / X_std
    for l in range(num_layers - 1):
        W = params[f'{prefix}_W{l}']
        b = params[f'{prefix}_b{l}']
        g = params[f'{prefix}_g{l}']
        V = W / np.linalg.norm(W, axis=0, keepdims=True)
        H = H @ V
        H = g * H + b
        if l < num_layers - 2:
            H = H / (1.0 + np.exp(-H)) * 1.0 * (1.0)  # H * sigmoid(H)
    return H
H*tf.sigmoid(H) は SiLU なので、PyTorch なら F.silu そのままです。V = W/norm(W, axis=0) の正規化をforward の中で毎回やる点だけ落とさないでください。ここを忘れると値がまったく変わります。
